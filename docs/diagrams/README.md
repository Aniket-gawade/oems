# OEMS Diagrams

This folder contains architecture and data diagrams for OEMS.

## Files

- `architecture.md`: service and infrastructure architecture
- `db-er.md`: conceptual database/entity model
- `order-flow.md`: create order flow with simulator execution modes

## Notes

- Diagrams are written in Mermaid so they stay version-controlled with code.
- Update these files when service boundaries, APIs, or schema change.
